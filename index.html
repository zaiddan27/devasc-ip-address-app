Part.02
Francis

We chose Option 2: a new IPv4/IPv6 address app.

It fits network technicians, the people the request came from. The APIs need no key, so everyone could run it on day one and nothing secret could leak into a public repo. Building from scratch let us split the work into one module per person. And it left room to add real tools.

Part.09
All four · what went wrong and what we did

Four real problems, four fixes.

  • 01Wrong account. Elijah's pull request was opened as #3 from John Patrick's account. We closed it and Elijah opened #5.
  • 02Wrong folder. The UI test file landed outside tests/, so the test runner missed it. It was moved twice until it ran.
  • 03No IPv6 at home. The app now says so instead of failing, and we tested IPv6 on a mobile hotspot.
  • 04"Private" was too broad. Python counts documentation ranges as private. We limited Private to RFC 1918.
